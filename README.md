# جولة البيت ثلاثية الأبعاد

نموذج ثلاثي الأبعاد لمنزل من طابقين (14 × 16 م) مبني من المخطط، مع جولة تلقائية وفيديو.

## الملفات
- `index.html` — الجولة التفاعلية؛ تفتح في أي متصفح حديث (تحتاج اتصالاً بالإنترنت لتحميل مكتبة three.js).
- `output/house-tour.mp4` — فيديو الجولة (1280×720).
- `output/house.glb` — النموذج ثلاثي الأبعاد (يفتح في 3D Viewer على ويندوز، أو على الآيفون، أو في Blender).

## التحكم في الجولة التفاعلية
- اسحب بالماوس للالتفات، وامشِ بالأسهم أو W A S D (Shift للإسراع).
- على الجوال: العصا للمشي والسحب للالتفات.
- «منظر علوي» يعرض كل طابق من الأعلى بدون سقف.

## إعادة التصدير
```bash
npm install
npm run video   # يصدّر output/house-tour.mp4
npm run glb     # يصدّر output/house.glb
```
يتطلب Node.js و ffmpeg و Playwright (Chromium).

## افتراضات من المخطط
- منسوب الطابق الأرضي 0.9 م فوق الشارع (5 درجات أمامية)، وارتفاع السقف 3 م، والطابق الأول مطابق للأرضي.
- المساحات الزرقاء: فناء مبلّط في الأرضي، وبرندا بدرابزين زجاجي في الأول.
- النقاط الخضراء في واجهة المخطط نُفّذت أعمدة تحمل البرندا الأمامية.
